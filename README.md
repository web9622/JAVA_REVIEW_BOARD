# 📚 JAVA_REVIEW_BOARD (자바 복습 게시판 프로젝트)

## 🌟 프로젝트 개요

본 프로젝트는 자바(Java) 언어와 데이터베이스(DB) 연동 기술을 복습하고 웹 애플리케이션의 기본 구조를 이해하기 위해 구현된 게시판(Board) 시스템입니다.

**주요 목적:**
1.  자바 언어의 기본적인 문법 및 객체 지향 프로그래밍(OOP) 복습.
2.  JDBC 또는 ORM을 활용한 데이터베이스(DB)와의 연동 로직 학습.
3.  웹/콘솔 기반의 CRUD(Create, Read, Update, Delete) 기능 구현을 통한 기본적인 백엔드 로직 이해.

### 주요 기술 스택

* **개발 언어:** Java
* **데이터베이스:** MariaDB / MySQL (혹은 프로젝트에서 사용된 DB 명시)
* **데이터 연동:** (프로젝트에서 사용된 기술에 따라 명시, 예: JDBC, Spring Data JPA 등)
* **환경:** (프로젝트 성격에 따라 명시, 예: Spring Boot, Servlet/JSP, 콘솔 애플리케이션 등)

---

## 🛠️ 기능 목록

이 게시판 프로젝트에서 구현된 주요 기능은 다음과 같습니다.

* **게시글 생성 (Create):** 새로운 제목과 내용을 입력하여 게시글을 등록합니다.
* **게시글 조회 (Read):**
    * 전체 게시글 목록을 조회합니다.
    * 특정 게시글의 상세 내용을 조회합니다.
* **게시글 수정 (Update):** 기존 게시글의 제목 또는 내용을 수정합니다.
* **게시글 삭제 (Delete):** 특정 게시글을 삭제합니다.
* **(선택적) 사용자 인증:** 로그인/회원가입 기능을 통해 게시글 작성자를 관리합니다.

---

## 🏗️ 프로젝트 구조 (Package Structure)

프로젝트의 핵심 로직은 역할에 따라 다음 패키지로 분리되어 있습니다.
(최상위 패키지 이름) 

├── domain // 데이터 모델 (Entity/VO) <br>
├── repository // 데이터베이스 접근 및 CRUD 처리 <br>
├── service // 비즈니스 로직 및 트랜잭션 관리 <br>
└── controller // 사용자 요청 처리 (입력/출력 관리)

## 🚀 환경 설정 및 실행 방법

### 1. 데이터베이스 준비

1.  MariaDB 또는 MySQL 등 사용할 데이터베이스를 설치하고 실행합니다.
2.  데이터베이스 접속 정보(스키마, 사용자명, 비밀번호)를 설정합니다.
3.  (필요한 경우) 테이블 생성 SQL을 실행하여 `BOARD` 테이블을 만듭니다.

### 2. 설정 파일 수정

프로젝트 내의 설정 파일 (예: `application.properties` 또는 JDBC 설정 파일)에 **데이터베이스 연결 정보**를 자신의 로컬 환경에 맞게 수정합니다.

### 3. 프로젝트 실행

1.  IDE (IntelliJ IDEA, Eclipse)에서 프로젝트를 로드합니다.
2.  (Spring Boot 프로젝트일 경우) 메인 애플리케이션 클래스를 실행합니다.
3.  (콘솔 프로젝트일 경우) 메인 메서드를 실행하여 게시판 기능을 테스트합니다.
